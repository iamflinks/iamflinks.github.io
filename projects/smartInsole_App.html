Smart Insole System

Overview
I designed and developed a smart insole system to perform real-time gait analysis. This wearable technology integrates custom flexible sensors, embedded electronics, and mobile software to capture and analyze walking patterns.

Highlights:

  • PCB Design: Created compact, multi-layer boards for the data acquisition module.

  • Flexible Sensor Design: Engineered and manufactured thin, conformable pressure sensor arrays.

  • Real-Time Data Processing: Implemented algorithms for on-board signal processing and feature extraction.

  • Android App Development: Built a user-friendly interface for displaying gait metrics and sensor data.

  • Product Integration: Seamlessly combined hardware and software components into a functional prototype.

Learning Outcomes - Through this project, I gained hands-on experience in:

  • PCB design and layout

  • Flexible electronics design

  • Embedded systems programming

  • Wireless communication protocols

  • Mobile app development

  • Signal processing and data analysis

  • Product design and integration

  • Project management

Conclusion
With this project, I demonstrated my ability to conceptualize, design, and implement a complete wearable sensing system, from custom hardware to user-facing software. The resulting smart insole prototype showcases my skills in electronics design, embedded systems, mobile app development, and my capacity to manage complex technical projects.
